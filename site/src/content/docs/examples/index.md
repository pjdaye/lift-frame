This section provides **worked examples** you can use to teach LIFT + FRAME, and to derive test strategy **before harm**.

- Start with the incident’s **LIFT classification** (where it broke, how it chained).
- Define **FRAME correctness** (invariants, envelopes, liveness, evidence).
- Derive **oracle-first** checks and layered tests.
