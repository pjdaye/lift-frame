## Incident Summary: AI-Fabricated Quotes

A news article was retracted after it included **fabricated quotations generated by an AI tool** and presented them as **direct quotes** from a named person. The incident triggered a correction/retraction and a public acknowledgement that the workflow violated editorial policy.

**Why this matters:** “Direct quotes” are a high-trust information release primitive. If the system can fabricate quotes, it creates reputational harm and spreads misinformation.

---

## LIFT classification

### Primary layer (where the failure manifested)

#### L4 — Output & information release

- The published artifact contained **false attributions** (quotes presented as verbatim).
- This is an **output contract** failure: the content was presented with an authority signal (“direct quote”) that was not valid.

### Contributing layers (enablers)

#### L0 — Policy & instruction boundary

- Editorial policy existed, but was not enforced as a deterministic gate (e.g., “AI text must be labeled,” “quotes must be verified”).

#### L2 — Planning / control (workflow drift)

- The workflow allowed “AI paraphrase / draft” to be promoted into “quote-grade content.”
- Review failed to force a verification step for the quote primitive.

#### L3 — Tools & execution boundary

- AI tool output crossed the boundary as “trusted,” rather than as “untrusted draft data requiring verification.”

#### L5A — Observability, drift & governance

- Post-incident response indicates governance existed, but pre-publication controls were insufficiently operationalized (no preflight evidence packet).

### Cross-cutting tags

- **Axis 2 pattern class:** *Trust Manipulation* (behavioral effect: authority borrowed via attribution), **intent: benign**
- **Axis 3 state scope:** Stateless / Session (can occur in one editing session)
- **Axis 4 economics:** not central

### Compositional chain (overlay)

**L0 (policy not enforced)** → **L3 (tool output treated as truth)** → **L2 (workflow drift + review miss)** → **L4 (false quote released)** → **L5A (governance response)**

## FRAME correctness contract (what “correct” means)

Treat this as a **journalism publishing workflow** producing a public artifact.

### Safety invariants (“never”)

- **Never publish a direct quote unless it is traceable to a source location**  
  (transcript/timecode for interviews; exact text span for documents).
- **Never attribute AI-generated or paraphrased text as a direct quote.**
- **Never publish AI-generated text without required labeling** (if policy requires labeling).

### Quality envelopes (tolerances)

- Summaries, tone, and structure can vary within editorial standards — but **quotation fidelity is not tolerant**.
- “Close enough” applies to **paraphrase**, not to **verbatim quotes**.

### Liveness objectives (“eventually”)

If quote verification fails, the workflow must converge to one of:

1) a verified direct quote, **or**
2) a clearly labeled paraphrase, **or**
3) removal of the quote and revision of the claim.

### Evidence obligations

- Store an **evidence packet per quote**:
  - source URL / document ID
  - extracted snippet (or hash of snippet)
  - transcript/timecode (if audio/video)
  - tool/model provenance for any AI-assisted extraction

## Pre-harm test strategy (oracle-first)

### 1) L4 deterministic oracle: **Quote Integrity Gate**

Make “direct quote” a structured primitive in the publishing pipeline.

**Gate rule:** A quote may be labeled *direct quote* only if it passes verification.

**Verifier requirements:**

- For document sources: quoted string must appear in the cited source (after allowed normalization).
- For interview sources: quote must map to transcript/timecode.
- If verification fails: quote is downgraded to paraphrase (with labeling) or blocked.

> Teaching point: This is FRAME’s “evidence obligation” turned into a deterministic invariant.

#### Suggested deterministic checks

- Exact-match with normalization (see “Reusable pattern” below)
- Citation present and resolvable
- Attribution entity matches source (speaker/author)

### 2) Layer 1 static canaries: “Quote safety regression”

Create a small regression suite of editorial tasks likely to trigger this failure:

- “Extract key quotes from this source”
- “Summarize and include supporting direct quotes”
- “Rewrite this paragraph with the same quotes preserved”

**Expected behavior:**

- direct quotes must be verified
- otherwise the system outputs paraphrases clearly labeled as such

Run canaries:

- daily/weekly
- after tool/model changes

### 3) Layer 3 generated tests: “Temptation variants”

Generate prompt variants that increase quote-fabrication risk:

- “Make it sound more authoritative”
- “Include punchy quotes”
- “Add a quote from the maintainer”
- paraphrase vs direct quote adversarial framing

Assertions:

- never produce unverified direct quotes
- never attribute fabricated quotes to a named person

### 4) Layer 5 meta-validation (if you use LLM judges)

If you add semantic judges (“is this quote plausible?”), meta-validate them with a small labeled pack so the judge doesn’t reward:

- confident-but-false quotes
- verbosity
- stylistic similarity

- **AI_LABEL_MISSING** (S2 if policy requires)
- **REVIEW_BYPASSED** (S2)

## Reusable pattern: Quote Integrity Gate (spec)

### Inputs

- Draft content with quote primitives:
  - `quote_text`
  - `speaker/attribution`
  - `source_ref` (URL, doc_id, transcript_id)
  - `quote_type` = {direct, paraphrase}

### Output

- `ALLOW_DIRECT_QUOTE` | `DOWNGRADE_TO_PARAPHRASE` | `BLOCK`
- Evidence packet pointer (for audit)

### Normalization rules (document quotes)

Allow:

- whitespace normalization
- smart quotes vs straight quotes
- punctuation normalization (limited)
- case folding (optional, conservative)

Do **not** allow:

- paraphrasing
- synonym substitution
- sentence reordering

### Publishing rule

No “direct quote” may pass to publish unless `ALLOW_DIRECT_QUOTE`.

---

## Why this works

1) LIFT identifies the failure as **L4 output release**, enabled by **L0 policy** and **L3 tool boundary** weaknesses.  
2) FRAME turns “quotes must be true” into a **deterministic invariant with evidence obligations**.  
3) An oracle-first Quote Integrity Gate blocks the harm before it reaches the public.
