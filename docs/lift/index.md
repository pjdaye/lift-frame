# LIFT

**LIFT** is a lifecycle-anchored fault & threat taxonomy for AI-enabled systems.

It is designed to support:
- risk analysis and fault hypotheses
- test strategy design (including layered assurance patterns)
- incident classification and operational dashboards

LIFT has:
- **Axis 1:** lifecycle layers (L0–L5B)
- **Axis 2–4:** cross-cutting axes (attack patterns, state scope, economic exploitability)
- a required scenario overlay for **compositional (chained) risks**
